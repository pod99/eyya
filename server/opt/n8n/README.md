# n8n

Этот шаблон разворачивает систему автоматизации n8n в Docker и настраивает обратный прокси на базе nginx. Для хранения данных используется папка `n8n_data`, которая должна принадлежать пользователю с UID 1000 (пользователь `node` в контейнере). Скрипт `start.sh` создает и настраивает эту папку автоматически.

## Запуск

`start.sh [ДОМЕН]`

- При указании домена будет выпущен сертификат Let's Encrypt и сервис станет доступен по HTTPS.
- Если домен не указан, будет использован IP‑адрес сервера и создан самоподписанный сертификат.

После выполнения скрипта файл `/tmp/n8n/return.txt` содержит данные для доступа:

```
url=https://<домен или IP>
login=admin
password=<сгенерированный пароль>
```

Скрипт также включает ufw, разрешая входящие соединения только на порты `22`, `80` и `443`.

## Состав

- **n8n** — контейнер приложения, слушает `127.0.0.1:5678`.
- **nginx** — обратный прокси, перенаправляющий трафик на контейнер.

Конфигурация Nginx включает необходимые заголовки и параметры для корректной работы WebSocket и SSE‑соединений, поэтому активация workflow происходит без ошибки «Connection Lost».
